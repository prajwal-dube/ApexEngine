PROCESS-LOCAL MEMORY

LRU + LFU cache

Hash Maps and doubly linked lists. Frequency-first eviction, recency for ties. Cache state is disposable.

ONE ORDER AUTHORITY

Matching writer

Bounded FIFO queue. Price then arrival priority. Calculates fills from authoritative database state.

PERSISTENT STATE

MongoDB replica set

Transaction commits the book, order states, trades and idempotency receipt together.

COMMITTED CHANGE FAN-OUT

Change streams

Every gateway independently observes book changes, invalidates its local cache, and updates its own clients.
